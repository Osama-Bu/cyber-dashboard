# Hash Generator and Identifier

## Description
This Python tool generates common cryptographic hashes for cybersecurity learning.

## Supported Hashes
- MD5
- SHA1
- SHA256

## How to Use
1. Run the Python file.
2. Enter the text you want to hash.
3. The tool will display the generated hashes.

## Educational Purpose
This project is created for learning hash functions and basic security concepts.
